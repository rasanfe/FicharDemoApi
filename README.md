# ⚙️ FicharDemoApi

API del ejemplo de fichaje/control horario, con el ORM DataWindow de Appeon (.NET DataStore), consumida por la app React Native [FicharDemo](https://github.com/rasanfe/FicharDemo). Demo de 2024.

> 🆕 **Versión de 2026:** [rasanfe/AppeonSpain2026](https://github.com/rasanfe/AppeonSpain2026), de la charla
> *Modernizando PowerBuilder con tecnologías web* (Barcelona, 27-10-2026).
> Allí la app de fichar es una **web React instalable como PWA** (el móvil sin APK),
> la API pasa a **.NET 10** con JWT, y todo ello vive también **dentro de PowerBuilder**.
> Este repositorio se conserva tal cual, como la demo de 2024.
